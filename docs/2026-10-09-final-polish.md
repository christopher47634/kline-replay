# 2026-10-09 · 雾蓝档案馆

以 Claude 融合版成果 `7849edb` 为基线，保留六个年份、盲盒、历史时刻、任务卡、决策回放和音乐结算。

## 视觉

- 默认盘口改为雾蓝灰底、珍珠白卡片、深蓝文字与古铜金强调；纸面与简约保留各自字体和阅读风格。
- 首页以悬浮玻璃历史行情卡组织图形，保留粒子聚合和交互；无 WebGL 时使用真实收盘序列的矢量图。
- 统一圆角、边缘高光、柔影；桌面设置抽屉改为有外边距的圆角浮层。
- 游戏、结算、音乐、导出海报和分享预览统一浅色材料。涨跌、段位与人格颜色按浅底调整。
- 三套主题的设置缩略图从实际游戏页面重新生成。

## 修复

- 任务/年份参数只允许自身属性，阻止 `constructor`、`__proto__` 等被误当成有效内容。
- 完成的盲盒清除存档后，同时恢复内存状态；未完成的局继续保留。
- 浏览器存储不可用或 JSON 损坏时，正常进入游戏，避免永久加载。
- 挑战链接遇到已有存档时，明确提供保留原局或开启新挑战，避免忽略链接任务。
- 离开游戏时取消结算计时器；弹窗打开时阻止底层游戏快捷键误触。
- 放大镜保持在视口以内；修正事件与音乐回调依赖。
