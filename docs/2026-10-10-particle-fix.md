# 首页粒子图停在散开状态

## 复现与原因

线上 `ab01e31`：等待聚合和走势播放完成，打开阅读设置，放大一次字号，关闭设置。WebGL 实际接收的 `uProgress`、`uPlay` 从 `1 / 1.05` 变成 `0 / 0`，等待后仍不恢复。

`shaderMaterial` 的初始 uniforms 对象在每次 React 渲染时重建。React Three Fiber 把新对象里的零写回材质，而开场动画已经结束。另一方面，几何变化会重启动画，所以窗口尺寸或配色变化还会触发不必要的重播。

## 修复

- 固定初始 uniforms 对象引用，动画继续操作材质的实际 uniforms。
- 动画按组件挂载运行，几何尺寸或颜色变化只更新图形，不重置进度；释放替换的几何资源。
- 鼠标推力最大从 66px 降至 6.4px；移出画布立即清除推力，关闭交互时也清除。
- 空闲呼吸按实际鼠标移动计时，保留原来的聚合、走势播放和柔光效果。

## 验证方法

使用 `scripts/check-hero-particles.js`，在 Playwright CLI 已打开的首页执行 `run-code --filename=scripts/check-hero-particles.js`。脚本只在测试浏览器拦截 WebGL 参数，不向产品添加探针。

已通过：字号变更、强调色变更、涨跌配色变更、1120/760/1440px 缩放、鼠标进入与移出。各步骤聚合进度保持 1，播放进度保持 1.05；移出后鼠标影响点恢复到画布外。

同一专项脚本在旧线上版本复现字号变更后 `0 / 0` 的失败，在修复版通过。生产构建及定向 lint 通过；13 项现有浏览器回归通过，覆盖动效、WebGL 降级、触屏、省电和页面切换。
